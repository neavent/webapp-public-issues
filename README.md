# Neavent Webapp - Public Issues

Welcome to the public issue tracker for the **Neavent Webapp**. 

This repository is dedicated to gathering feedback from our users. Since the source code for the webapp is not hosted here, please use this space strictly for reporting bugs, requesting new features, or reporting security concerns.

## 📝 How to Contribute

We accept issues in **English** or **German**.

Before submitting a new issue, please use the search function to check if someone else has already reported the same problem or requested the same feature.

### 🏷️ Title Conventions

To help us process your request faster, please start your issue title with one of the following prefixes:

* **`BUG:`** — If you found an error or something isn't working as expected.
    * *Example:* `BUG: Login button does not respond on mobile`
* **`FEAT:`** — If you have an idea for a new feature or improvement.
    * *Example:* `FEAT: Add Dark Mode support`
* **`SEC:`** — For security-related reports.
    * *Example:* `SEC: Session does not expire after logout`

### ℹ️ Issue Content

Please provide as much detail as possible in the description:

* **Description:** A clear and concise description of the issue or idea.
* **Steps to Reproduce (for Bugs):** Step-by-step instructions to make the bug happen.
* **Expected Behavior:** What you expected to happen.
* **Screenshots/Video:** Visuals are very helpful!
* **Environment:** Browser version, OS, or device used.

---

> **Note:** Please do not share sensitive personal data (passwords, API keys, etc.) in public issues.

Thank you for helping us improve Neavent!
